## 1. Why the Cybersecurity Industry Needs a New Generation of Professionals

Cybersecurity is no longer limited to antivirus software, firewalls and basic network monitoring.

Modern security professionals need to understand how applications are built, how APIs communicate, how authentication works, how cloud infrastructure is configured and how vulnerabilities can be exploited.

At the same time, AI is changing how security teams work.

Consider some emerging applications:

* AI-assisted reconnaissance and information gathering.
* Automated vulnerability discovery and analysis.
* Intelligent security testing workflows.
* AI-assisted code and configuration review.
* Security automation using Python and other tools.
* Agentic systems that can plan and execute multi-step security tasks under human supervision.

These developments do not eliminate the need for cybersecurity professionals.

Instead, they increase the importance of people who understand security deeply enough to build, guide and validate AI-powered security systems.

The industry needs professionals who can combine technical security knowledge with practical AI capabilities.

**CAAPT is designed around this intersection.**

## 3. What Will You Learn?

CAAPT follows a progressive learning approach, moving from cybersecurity foundations towards AI-assisted security workflows and agentic systems.

### Module 1: Cybersecurity and Penetration Testing Foundations

Before understanding AI-powered security, learners need to understand the fundamentals of cybersecurity.

This stage introduces the basic concepts behind ethical hacking and security assessments.

Topics include:

* Introduction to cybersecurity.
* Understanding ethical hacking.
* Attack surfaces and threat models.
* Reconnaissance fundamentals.
* Common security weaknesses.
* Introduction to [[penetration-testing]] methodology.
* Responsible and authorised security testing.

The objective is to help learners understand how security professionals approach an application or infrastructure from an attacker's perspective.

### Module 2: Reconnaissance and Vulnerability Discovery

A security assessment begins with understanding the target.

Learners explore how security professionals collect information, identify exposed services and map potential attack surfaces.

Topics include:

* Passive and active reconnaissance.
* Network discovery.
* Service enumeration.
* Information gathering.
* Identifying exposed assets.
* Vulnerability discovery and [[vulnerability-assessment]].
* Understanding security assessment results.

Practical exposure includes tools such as Nmap and Wireshark, along with controlled security-testing environments.

### Module 3: Web Application Security and Exploitation

Web applications are among the most common targets for cyberattacks.

This module introduces learners to common web security weaknesses and how they can be identified and validated in authorised environments.

Topics include:

* Web application architecture.
* Authentication and authorization.
* Common web vulnerabilities, including the [[owasp-top-10]], [[sql-injection]] and [[xss]].
* Input validation and injection issues.
* [[api-security]] fundamentals.
* Vulnerability analysis.
* Exploitation concepts.
* Understanding security impact.

Learners gain exposure to tools such as Burp Suite and intentionally vulnerable applications.

The focus is not simply on running tools. It is on understanding what the results mean and how vulnerabilities affect real applications.

### Module 4: Exploitation and Defensive Security Fundamentals

Understanding an attack is only one part of cybersecurity.

Professionals also need to understand how attacks can be detected, investigated and mitigated.

This module introduces:

* Exploitation fundamentals.
* Understanding attack chains.
* Security misconfigurations.
* Basic post-exploitation concepts.
* Threat identification and [[mitre-attack]].
* Defensive security fundamentals.
* Understanding remediation.

The objective is to connect offensive security knowledge with the defensive measures required to protect systems.

### Module 5: Artificial Intelligence for Cybersecurity

This is where the programme moves beyond conventional penetration-testing training.

Learners explore how AI can support cybersecurity workflows and help security professionals work more efficiently.

Topics include:

* Introduction to AI and large language models.
* AI-assisted security analysis.
* Prompting techniques for cybersecurity.
* AI-assisted reconnaissance and vulnerability analysis.
* Security automation using Python.
* Local AI model workflows.
* Understanding the limitations of AI-generated security findings, including [[prompt-injection]] and [[llm-security]] risks.

Tools and technologies introduced include Python, Ollama and relevant AI-assisted security workflows.

The important lesson is that AI should assist security professionals, not replace technical validation and human judgement.

### Module 6: Agentic AI and Autonomous Security Systems

The final learning stage explores agentic AI.

Unlike a traditional AI assistant that responds to individual prompts, an agentic system can work through a sequence of tasks, use tools and make progress towards a defined objective.

In cybersecurity, this creates opportunities for building intelligent systems that can support multi-step security assessments.

Learners explore:

* Agentic AI fundamentals.
* AI agents and tool integration.
* Multi-step task execution.
* Planning and reasoning workflows.
* Security automation.
* Human-in-the-loop approval.
* Responsible use of autonomous security systems.

The focus is on understanding how AI agents can support security work while keeping meaningful human oversight.

## 4. Build Something Practical: The AutoSec AI Capstone Project

Learning concepts is important. Applying them is what makes the experience meaningful.

CAAPT includes a capstone project focused on building an **AutoSec AI penetration-testing copilot**.

The idea is to bring cybersecurity workflows and agentic AI together in a practical project.

Instead of treating every security activity as an isolated manual task, learners explore how an AI-assisted system can help organise and support different stages of an authorised assessment.

The project introduces learners to concepts such as:

* Security task planning.
* Tool integration.
* AI-assisted reconnaissance.
* Organising assessment results.
* Vulnerability analysis.
* Multi-step agent workflows.
* Human approval and validation.

The goal is not to create an uncontrolled autonomous hacking system.

The goal is to understand how intelligent systems can assist security professionals in performing structured, authorised security assessments.

This project provides an opportunity to connect the technical concepts learned throughout the programme.
